# Обучение и передача исследовательской модели

`train.py` — полный файл обучения CatBoost, включённый в ZIP вместе с
`features.py` (точная подготовка признаков), `loader.py` (загрузка весов и
прогноз) и `model.cbm` (веса). Для обучения нужны локальные, не хранящиеся
в Git пакеты Q2 v5, Q3/A v4, B3 v2 и принятые временные folds соседнего
эксперимента. Скрипт проверяет их хеши перед обучением и отказывается
перезаписывать существующий результат.

Запуск из корня репозитория с папкой `ml/service_candidate` в нём
(из ветки ML или скопированной из ZIP). Распакованный ZIP содержит эту папку
внутри каталога модели; её нельзя подменять другой версией `features.py`,
поскольку загрузчик сверяет хеш преобразования признаков.
Для повторного обучения нужны также перечисленные выше исходные пакеты:

```powershell
python -m ml.service_candidate.train `
  --data output/ml-experiment-round2/coverage/data `
  --q2 output/q2-a-full-sparse-20260926-v5 `
  --q3 output/q3-a-coverage-reentry-20260927-v4 `
  --b3 output/r3-b-full-months-20260925-v2 `
  --verification output/q3-a-coverage-reentry-verification-20260927-v4.json `
  --reference output/ml-experiment-round2/coverage/retrained `
  --output output/service-model-retrained-new
```

Модель обучается на 2019, 2020, 2022, 2023 годах: все назначенные
положительные часы и детерминированные 2% отрицательных. Все 121 исходное
поле поступают из причинных Q2/Q3 packs; локальная обработка строит 304
поля CatBoost. Модель и конфигурация фиксируются по 2024 году из соседнего
эксперимента. Открытый 2025 год и старый test 2026 не подбирают настройки.
`Неисправен` — будущая запись журнала, не подтверждённая физическая поломка.
Это воспроизведение отдельного исследования соседней ветки, а не выбранная
рабочая модель из более позднего сравнения Q3/B. То сравнение также не нашло
вариант, выполнивший обе целевые метрики; действующий R6 не заменён.

Пример в Python при **уже рассчитанных** прошлых 121 полях:

```python
from pathlib import Path
from ml.service_candidate.loader import ResearchRiskModel

model = ResearchRiskModel(Path("output/service-model-journal-failure-20260928-v1"))
result = model.score(hourly_frame)
```

`hourly_frame` — DataFrame с полным списком `base_feature_names` из
`model_metadata.json` и обязательным `admission_status`. Допустимые значения
статуса: `eligible`, `unknown`, `excluded`. Можно передать `channel_id` и
`prediction_time` для идентификации результатов. Нельзя передавать target,
будущий эпизод или время появления будущей метки. Строки с `unknown` и
`excluded` получают пустой score, не нулевой риск. Для `eligible` выдаётся
`risk_score`, **не калиброванная вероятность**. `warning` всегда пуст:
автоматические предупреждения и действия не разрешены этим пакетом.

ZIP нельзя просто положить в нынешний `backend` и ждать реальных прогнозов:
его существующие API-ответы демонстрационные. Сервису требуется отдельный
причинный расчёт 121 поля из поступившей истории и явного допуска в момент
`t`; эту интеграцию и время поступления событий ещё надо согласовать.
Исследовательский Q3-допуск не утверждён совместно, а метрики
Precision > 0.7 и Recall > 0.5 не подтверждены. Пакет годится для загрузки,
проверки интерфейса и офлайн-анализа, но не для эксплуатационных действий.
