# Round 7: замороженный исследовательский кандидат

Здесь лежат три проверенных по SHA-256 компонента эксперимента:
линейная модель, вспомогательная CatBoost и специалист для стандартных
предупреждений дыма/фазы. `Round7ResearchModels.score()` принимает только
причинные 121 признак Q2/Q3, явный статус допуска и время последней
`Норма`; возвращает баллы и результаты статических фильтров.

API в `main` теперь использует эти компоненты для причинного расчёта из новых
сырых CSV/7z и выдаёт record-only предупреждение после статических ворот.
Опубликованные 3 758 предупреждений, Recall 52,29% и нижняя граница Precision
29,80% получены полной ретроспективной политикой: проверенный допуск Q2/Q3,
24-часовое подавление, наблюдённое начало и завершение эпизода и восстановление
после него. Периодическая выгрузка не доказывает непрерывность канала, поэтому
онлайн-адаптер не приписывает себе эти офлайн-метрики.

2025 год использовался при выборе правил Round 7; это открытые данные
разработки, не независимый тест. Автоматические действия не разрешены,
физическая поломка не является подтверждённой целью.

Минимальный вызов после установки корневого `requirements.txt`:

```python
from ml.experimental_round7 import Round7ResearchModels

models = Round7ResearchModels()
scores = models.score(hourly_features)
```

`hourly_features` должен содержать точные признаки Q2/Q3, `channel_id`,
`prediction_time`, `sensor_type`, `admission_status` и
`last_explicit_normal_at`. Метки и будущие события на вход запрещены.
Для переключения веб-сервиса ещё нужна независимая сверка пересчёта этих
полей из загружаемого журнала и перенос полной хронологической политики.

На локальных артефактах 2025 года сравнение 100 Q2-строк с сохранёнными
баллами дало максимальное абсолютное расхождение `1,8e-9` для линейной
модели и `4,7e-9` для CatBoost. Для 100 строк специалиста расхождение
составило `1,1e-8`. Это проверка переноса весов и предобработки, **не**
проверка полного потока предупреждений в API.
