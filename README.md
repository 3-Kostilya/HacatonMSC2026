# Прогноз неисправности дымовых датчиков

Текущая работа по новому ТЗ: **Milestone 1 — подготовка событий всех типов каналов в Parquet**.
Реализация, границы проверки и дальнейшие подэтапы описаны в
[отчёте Milestone 1](docs/milestone1-ingestion.md). Запуск ограниченной проверки:
`python -X utf8 analysis/prepare_ingestion.py`. Новые признаки, псевдометки и модели
в этом milestone не строятся. Описанный ниже эксперимент с дымовыми датчиками
сохранён как прежняя исследовательская работа; его target не перенесён в новый pipeline.

Исследовательский проект на CatBoost для журналов мониторинга инженерной инфраструктуры. Модель прогнозирует начало зарегистрированного состояния **«Неисправен» в ближайшие 24 часа** у каналов типа **«Датчик дыма»**.

Это производная метка по журналу. Подтверждения физического отказа и результатов ремонта в исходных данных нет. Флаг `тревожное` используется как признак, но не определяет целевую переменную.

## Установка

Проверено на Python 3.14. Для чтения архивов нужен 7-Zip: `7z` или `7zz` в PATH. В Windows также поддерживается стандартная установка 7-Zip. Другой путь можно указать через переменную окружения `SEVEN_ZIP`.

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

```bash
python -m pip install -r requirements.txt
```

## Данные

Исходные данные не входят в репозиторий. Для обучения нужны локальные файлы:
Если данные уже лежат в старой локальной `dataset/`, переименуйте её в `data/`:
Git не переносит игнорируемые исходные файлы вместе с обновлением кода.

```text
data/
  справочник_каналов_датчиков.csv
  ext-journal-2019.7z
  ...
  ext-journal-2026.7z
```

Формат журнала: `ид_события`, `ид_канала_данных`, `дата`, `время`, `тревожное`, `значение_датчика`.
Справочник должен содержать уникальный `ид_канала_данных` и `тип_датчика`. Каждый годовой архив содержит CSV журнала.

## Целевая переменная

Положительный класс — начало состояния `Неисправен` у дымового датчика в ближайшие 24 часа. Остальные наблюдаемые состояния считаются отрицательным классом для этой постановки. Состояния вроде `Затоплен` относятся к другим направлениям задачи и требуют отдельной разметки.

Поле `тревожное` используется как дополнительный признак для инференса, но не является целевой переменной.

## Обучение

Все команды выполняются из корня проекта.

Полное исследование:

```bash
python -X utf8 ml/smoke_failure/full_study.py
```

Обучение использует 2019-2023 годы, настройка числа деревьев и порога — 2024 год. Тест полностью отложен: 2025 год и январь-июнь 2026 года. Архив 2026 года неполный.

Исходный эксперимент 2022-2023:

```bash
python -X utf8 ml/smoke_failure/train.py
```

Результаты сохраняются в `output/smoke_failure_2019_2026/` и `output/smoke_failure/`: модель `.cbm`, метаданные, отчёт, метрики, графики и проверочные прогнозы. Они исключены из Git. Для пересчёта признаков и меток используется `--rebuild`.

## Прогноз

```bash
python -X utf8 ml/smoke_failure/predict.py --model-dir output/smoke_failure_2019_2026 --as-of 2026-06-22T12:00:00
```

По умолчанию история и результат берутся из каталога модели. Для своей выгрузки доступны `--events path/to/events.csv`, `--dictionary path/to/dictionary.csv` и `--output path/to/predictions.csv`. Поддерживаются исходный CSV и подготовленный Parquet. Время указывается в локальном формате журнала без часового пояса.

События после `--as-of` не используются. Оценка риска не выдаётся для уже неисправного датчика, неизвестного состояния, сообщения старше суток или истории короче суток. Пустая оценка не означает отсутствие риска.

## Результаты и ограничения

На тесте 2025-2026: Precision **1,000**, Recall **0,765**, F1 **0,867** по часовым примерам. В 2026 году Recall снижается до **0,495**. При одном предупреждении на канал в сутки обнаружено **67 из 227** доступных эпизодов. Простое правило по прошлым неисправностям имеет более высокий F1.

При строгой обработке пробелов из 3,96 млн записей получено только 5 222 размеченных часовых примера. Метрики относятся к этой выбранной наблюдаемой части истории, а не ко всему парку датчиков. Модель не подтверждена для эксплуатации.
