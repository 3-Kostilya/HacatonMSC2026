# Замороженные синтетические сценарии первого этапа

Версия генератора: `stage1-simulation-v1`. Параметры и seed `260919` зафиксированы
19 сентября 2026 года в `stage1/config/simulation_parameters.json`, до расчёта
метрик. Генератор создаёт `NormalizedEvent` и отдельный truth manifest; истинные
границы не записываются в события и доступны только оценщику.

## Разделение настройки и проверки

`tuning` начинается 1 марта 2025 года, а `synthetic_holdout` — 1 марта 2026 года.
У них разные исходные сегменты, cadence и величины воздействий. Оба набора имеют
чистый причинный префикс не короче семи дней. Параметры выражены в стандартном
отклонении собственной истории там, где неизвестны физические единицы. Результаты
holdout нельзя использовать для повторного выбора порогов под тем же номером версии.

## Девять сценариев

| Сценарий | Метка | Ожидаемое поведение |
|---|---|---|
| `numeric_gradual_drift` | positive | устойчивый числовой кандидат |
| `numeric_variance_increase` | positive | кандидат по длительному росту разброса |
| `numeric_level_shift` | positive | кандидат по сохраняющемуся сдвигу уровня |
| `numeric_single_spike_control` | control | одиночная точка не даёт кандидата |
| `discrete_rapid_switching` | positive | кандидат по частым переключениям |
| `discrete_ordinary_cycle_control` | control | штатный цикл не даёт кандидата |
| `single_alarm_control` | control | один alarm не является меткой отказа |
| `missingness_unknown_control` | control | `unknown`, детектор отказа неприменим |
| `common_outage_context` | positive | одна общая контекстная гипотеза |

В manifest каждого сценария входят `scenario_id`, тип метки, начало воздействия,
`failure_point` для положительного сценария, конец, каналы, тип датчика, ожидаемое поведение,
применимый способ обработки и ожидаемая cadence, если она подтверждена.

Сценарий разрыва намеренно использует нерегулярный ряд с неизвестной cadence. Внутри
разрыва нет синтетических строк и нет значения «неисправен»: молчание не превращается
в отказ. Этот интервал должен получить `unknown`, а не отрицательный пример или
локальный диагноз. Общий сбой содержит несколько синхронных каналов, но одну truth-
запись и один явно синтетический `object_id`; он не должен размножаться в
независимые физические поломки. Эта связь существует только внутри сценария и не
делает технический тег реальных данных идентификатором объекта.

## Воспроизводимый запуск

```powershell
python -m analysis.build_synthetic_holdout --suite all --output output/stage1
```

Результат — пары `*_events.jsonl` и `*_truth_manifest.json`. Тесты проверяют
детерминизм, полный состав сценариев, неизменность чистого префикса, разделение
параметров tuning/holdout и безопасную семантику неизвестной cadence.
