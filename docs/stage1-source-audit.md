# Аудит источников и ограниченный потоковый проход — День 1

Дата проверки: 19 сентября 2026 года. Машина: текущая Windows-среда проекта.

## Итог

Источники можно читать последовательно без распаковки на диск и без загрузки журнала в
память целиком. Ограниченный проход прочитал по 100 000 строк из каждого из восьми
источников событий: всего 800 000 строк за 9,29 с чистого времени CSV-разбора,
взвешенная скорость 86,2 тыс. строк/с. Все семь рабочих групп встретились хотя бы в
одном архиве. В пробе встретились 18 из 19 типов; редкий `9-секционный люк` не попал в
префиксы и требует адресной либо полной проверки позже.

Этот запуск — **не полный профиль журналов**. Диапазоны дат, частоты типов и покрытие
справочником ниже относятся только к первым 100 000 строк каждого источника. Пример
журнала проверен как отдельный источник и не суммируется с годовым архивом 2026 года.

## Комплект данных

- Годовые архивы есть за 2019, 2020 и 2022–2026 годы. Архив 2021 года отсутствует.
- Семь архивов занимают 1 462 906 938 байт (1,36 GiB) в сжатом виде; единственные CSV
  внутри них — 13 181 762 829 байт (12,28 GiB) в распакованном виде.
- Каждый архив содержит ровно один CSV. Для него сохранены имя, исходный размер, CRC,
  метод сжатия и остальные метаданные 7-Zip.
- Для всех архивов, примера и справочников рассчитан SHA-256. Полный манифест находится
  в `output/stage1/source_audit.json`.
- Доступен 7-Zip 26.01 x64 по пути `C:/Program Files/7-Zip/7z.exe`; в `PATH` команды
  `7z` нет. Скрипт также поддерживает `SEVEN_ZIP`, `7zz` и `7z`.
- Все проверенные CSV читаются как UTF-8; допускается BOM через `utf-8-sig`.
- Схема событий во всех пробах совпала: `ид_события`, `ид_канала_данных`, `дата`,
  `время`, `тревожное`, `значение_датчика`.

Схема справочника каналов состоит из пяти полей: `ид_канала_данных`,
`тип_инж_системы`, `тип_датчика`, `тег_инженерной_системы`, `название_датчика`.
В нём 11 485 строк, 11 485 уникальных ID и 19 типов; все типы однозначно попали в
заданную классификацию семи групп. Поля с ID объекта нет, поэтому проверить внешний
ключ `канал → объект`, уровень объекта, долю непривязанных каналов и отсутствие
размножения строк при таком соединении сейчас невозможно.

В справочнике объектов 95 строк и 95 уникальных ID, циклов в иерархии не найдено.
Родитель `3831` отсутствует среди этих 95 объектов. Это может быть внешний корень
сокращённой выгрузки, но до подтверждения считается неопределённостью.

14 302 из 800 000 пробных строк ссылаются на канал, которого нет в текущем

следует экстраполировать на весь журнал без полного прохода.

Скорость включает распаковку 7z и CSV-разбор с проверкой канала, группы, даты,
тревожности и возможности преобразовать значение в число. Она не включает будущую
запись Parquet и расчёт оконных признаков. Объём будущего Parquet сейчас честно не
оценивается: он зависит от типов столбцов, словарного кодирования и набора флагов.
Известная верхняя отправная точка для планирования диска — 12,28 GiB исходного CSV.

## Воспроизведение

Быстрый безопасный режим по умолчанию:

```powershell
python -X utf8 analysis/audit_stage1_sources.py
```

Другой предел строк и запуск тестов:

```powershell
python -X utf8 analysis/audit_stage1_sources.py --max-rows 250000
python -X utf8 -m unittest discover -s analysis -p "test_audit_stage1_sources.py" -v
```

`--skip-archive-hashes` ускоряет повторный диагностический запуск, но создаёт более
слабый манифест. Флаг `--full` предусмотрен только для явно запланированного полного
прохода; по умолчанию он не используется. Ограниченный процесс останавливает 7-Zip
после достижения лимита, и ненулевой код завершения экстрактора в этом режиме является
ожидаемым и записывается в аудит.

## Риски и решения для следующей работы

1. Получить обновлённый справочник с ID объекта. До этого признаки соседства,
   совместности по объекту и выводы об общей причине отключить.
2. Найти архив 2021 года либо формально зафиксировать разрыв истории.
3. Для `9-секционного люка` сделать адресную выборку по его девяти ID или полный
   потоковый проход: отсутствие типа в префиксе не означает отсутствие событий.
4. Исторические неизвестные каналы не отбрасывать молча. Хранить флаг качества и
   отдельно запросить версионный справочник каналов.
5. Префиксы архивов не являются случайной или стратифицированной выборкой. Их можно
   использовать для проверки совместимости и пропускной способности, но не для
   оценки распределений и порогов детектора.
6. Перед массовой подготовкой Parquet отдельно замерить запись типизированной схемы на
   одном одинаковом календарном интервале для всех типов; текущий тест измеряет только
   чтение, разбор и лёгкую агрегацию.
