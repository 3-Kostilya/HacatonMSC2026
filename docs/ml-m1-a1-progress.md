Начат 2026-09-22 на ревизии `76faf3f5cefd289688e7bce806b116eb1b6d58a9` после технического ревью M0 участником A (`ml-m0-a-review.md`).

Команда воспроизведения из корня проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 analysis/prepare_ingestion.py --full --output output/milestone1/full_20260922
```

Выход `output/milestone1/full_20260922.inprogress` является **незавершённым**.
Только опубликованный `output/milestone1/full_20260922/manifest.json` со
`status=complete` можно передавать B или использовать для M2. Повторный запуск
должен иметь другое имя выхода: pipeline не перезаписывает старые результаты.

Перед запуском: все семь доступных архивов 2019, 2020, 2022–2026, пример
журнала и оба справочника присутствовали; 2021 отсутствует. Свободно около
81 ГиБ на диске C. Суммарный несжатый размер архивных CSV по предыдущему
аудиту — около 13,2 ГБ. Пилот на 869 993 строках — не полный результат.

После завершения A проверяет: баланс входных строк по disposition, полноту
источников, число строк и сортировку всех Parquet, месяцы и семейства,
неизвестные каналы, дубликаты, карантин, качество связи и ресурсы. B1 затем
независимо проверяет полученный manifest и детерминированный фрагмент Parquet.
До этих проверок M1 не принят.
