# Q2/B: независимая сверка потолка Recall

Дата: 27.09.2026. Проверка B после [приёмки A](ml-q2-a-b-acceptance-and-oracle-review.md). Новая модель, порог, метки и правила предупреждений не выбирались. Исходные данные — 12 сохранённых файлов прогнозов B за validation 2025 и закреплённый список эпизодов Q2; их манифесты и файлы проверены по SHA-256. Старый test и исключённый год не использованы.

## Результат

Независимый код B (`analysis/verify_q2_oracle_b.py`) прочёл **16 202** положительных часа в сохранённых прогнозах. Они относятся к **1 359** доступным эпизодам из **2 142** назначенных. На каждом канале выполнено отдельное обратное динамическое программирование по часам с интервалом не менее 24 часов. Прямой жадный расчёт на каждом канале дал то же число. Для каждого эпизода проверено, что все его положительные часы занимают менее 24 часов: поэтому расписание с таким интервалом не может дважды засчитать один эпизод.

| Тип | Всего эпизодов | Доступно | Максимум с 24-часовым интервалом |
|---|---:|---:|---:|
| Дым | 1 118 | 903 | 705 |
| Состояние фазы | 335 | 246 | 211 |
| Температура | 408 | 2 | 2 |
| Газ | 56 | 53 | 53 |
| Остальные | 225 | 155 | 145 |
| **Все** | **2 142** | **1 359** | **1 116** |

Итог и разбивка по типам совпали с A. При текущей часовой сетке, допуске, метках, пустом начальном состоянии cooldown и правиле «одно предупреждение — один эпизод» предельный Recall равен **1 116 / 2 142 = 52,10%**. Для строгого `Recall > 0,5` нужны минимум **1 072** совпадения — **96,06%** идеальной ёмкости; запас составляет **44** эпизода. Исследовательская линейная модель B нашла 346, то есть текущий разрыв с целью нельзя закрыть одним только устранением ложных предупреждений.

Это **ретроспективный оракул с будущими метками**, не прогноз и не достижимое качество модели. Его выбор часов нельзя использовать как признак, обучающую выборку или рабочее расписание. Отдельный невыбранный эпизод не обязательно недостижим: оптимальных расписаний может быть несколько. Часы с неизвестной будущей меткой отсутствуют, как и в опубликованной оценке B.

Малый ZIP A `output/q2-a-verification-handoff-20260927.zip` в этом рабочем пространстве пока отсутствует. Поэтому числовой результат и типы независимо воспроизведены, но побайтовое сравнение с **его** `channel_capacity.parquet` и `oracle_schedule.parquet` не заявляется. Собственный отчёт и поканальные ёмкости B находятся вне Git в `output/q2-b-independent-oracle-20260927/`; SHA-256 манифеста `00c362af8797aa20e4e665b961c36e7e5edf69cf32c2aca4a514cca3eebadeb7`.
