# B1 — спецификация испытаний до настройки детекторов

> Реализация B2 и результаты проверки: [отчёт B2](ml-b2-synthetic-report.md).

Версия: `m1-b-scenarios-v1`, 2026-09-22. Владелец — B.
Это задание на стенд B2 и проверки B3/B4, а не результаты качества моделей.
2021 год исключён по прямому указанию пользователя: не используется ни для

## Положительные воздействия

Масштаб s = max(MAD/0,67449, разрешение датчика); вычисляется только на
чистом синтетическом прошлом. Разрешение задаётся сценарием. Отдельный фон
с MAD=0 проверяет корректность недоступности/резервного масштаба. Если
разрешение неизвестно, не придумывать физические единицы для реального канала.
Амплитуды и длительности ниже — сетка испытаний, одинаковая для всех методов.
Уровни 1s и короткие воздействия публикуются как трудные случаи отдельно;
для допуска из M0 используются объявленные устойчивые случаи ≥ 3s.

| Воздействие | Каналы и параметры | Что считается правильным результатом |
|---|---|---|
| bias/level | numeric и numeric-ветвь mixed; ±1/3/6s, длительность 6/12/48h | Устойчивый сдвиг уровня, начало/подтверждение раздельно |
| drift | numeric/mixed; линейное изменение ±3/6s за 24/48/168h | Дрейф, а не автоматическое объявление роста дисперсии |
| variance | numeric/mixed; шум ×2/4, прежняя медиана, 12/48h | Рост разброса с сохранением уровня |
| stuck | numeric; фиксация последнего значения на 12/48h при продолжающихся сообщениях | Залипание только на фоновых процессах, где вариативность ожидается |
| dropout | Только известная периодическая регистрация; отсутствие сообщений 3/6/24 ожидаемых интервала | Потеря наблюдаемости; не нулевое измерение и не физическая поломка |
| деградация связи | Те же каналы; интервалы ×2/4, потери 25/50/75%, 12/48h | Отдельное свидетельство качества связи с явной применимостью |
| переключения | state и state-ветвь mixed; частота ×3/6 от заданного штатного цикла, 6/24h | Устойчивое учащение смен; одиночное событие не положительный эпизод |
| смена режима | numeric/state; два штатных режима и новый устойчивый режим | Переход/нетипичность отдельно от целевой метки; редкость сама по себе не отказ |

Оба знака сдвига, разная частота регистрации, начало на границе часа и между
часами, новый канал, короткая история и восстановление обязательны. Сценарий
с двумя воздействиями, разделёнными восстановлением, должен дать два эпизода;
краткий выход ниже порога внутри воздействия не должен дробить один эпизод.
Для редких/неизвестных типов сначала проверяется пригодность по реестру;
неприменимый метод возвращает статус, не выдуманную оценку.

## Отрицательные контроли

| Контроль | Проверка |
|---|---|
| Обычный шум | Gaussian и тяжёлые хвосты на отдельных фонах; бюджет ложных эпизодов |
| Сезонность | Суточная/недельная компонента; обычный цикл не устойчивый bias |
| Штатные переключения | Регулярные и редкие допустимые события, без ускорения ради теста |
| Одиночный spike | Краткий выброс не подтверждает устойчивый псевдоэпизод |
| Общая смена среды | Без настоящей связи канал→объект нельзя утверждать локальную причину |
| Пробел выгрузки | Unknown/качество данных, не массовый отказ датчиков |
| Молчание регистрации изменений | Не объявлять dropout без известной периодичности |
| MAD=0 / короткое прошлое | Нет деления на ноль, NaN или уверенного нормального статуса без оснований |
| Значения -3276, 327.68, 999 и текст | Сохранять исходное представление; не удалять по «подозрительности» |

Для синтетических фонов контролей эталон известен. Реальный фон без экспертной
истины не считать нормальным автоматически; показывать нагрузку кандидатами
и объяснения отдельно от Precision/Recall/FP.

## Разделение и артефакты стенда

До настройки B2 выпускает tuning/holdout manifest: версия, `background_id`,
`parent_background_id`, исходный канал и интервал, seed, scenario_id, параметры,
хеш входа. Пересечение исходных каналов, отрезков и производных одного фона
запрещено. Holdout дополнительно содержит отложенные комбинации воздействий;
новый seed на прежнем фрагменте не делает набор независимым. М0 fixture остаётся
общедоступной регрессией. Эталонные onset/end/kind и параметры воздействия
хранятся отдельно от доступных модели событий.

Ожидаемые выходы B2: events, truth episodes, отдельные manifests и спецификация
пригодности. B3: scores и predicted episodes, start/confirmed/end, evidence,
версии и статусы. B4: один truth-эпизод даёт максимум один TP, повторы отдельно;
по каждой паре семейство/воздействие — Recall, Precision/F1, задержки,
ошибки вида, FP на наблюдаемые канало-дни, покрытие и unknown.
Числовые бюджеты, минимальные объёмы и критерии из `ml-m0-b-review.md`
сохраняются как предложение до совместного принятия A+B.

Для drift задержка считается от начала воздействия, а не от удобного момента
пересечения порога. Если метод не проходит критерий слабого воздействия, это
показывается в соответствующей ячейке отчёта, не удаляется из знаменателя.
Для прогноза будущий эпизод в `(t,t+24h]`; срабатывание после onset не TP
прогноза. Внезапное воздействие без предвестника — обязательный отрицательный
контроль прогнозируемости, не повод добавить будущую информацию в признаки.

## Приёмка данных M1 со стороны B

1. Источники: явный список разрешённых файлов, хеши, лимиты и фактические строки;
   результаты ограниченного чтения не выдаются за полную историю.
2. Все исходные поля и происхождение сверяются после повторного чтения источников
   с объединением clean + excluded, включая кратности. Баланс не ограничивается
   сравнением двух чисел в отчёте самого загрузчика.
3. Проверяются уникальность происхождения, отсутствие размножения при join,
   дубликаты всех шести полей, ссылки исключённых дублей, сохранение чисел/текста,
   повторные event_id с разными данными, неизвестные каналы и объектные связи.
4. Файлы читаются физически для проверки типов времени и порядка внутри раздела;
   статистика по типам и месяцам пересчитывается. Отсутствие строк какого-либо
   типа в префиксе не доказывает отсутствие этого типа в полной истории.
5. Для полного закрытия M1 нужен полный завершённый manifest от A и повторный
   аудит B на его артефактах; далее совместная приёмка. B1 на префиксах не
   заменяет A1 и не разрешает массовую псевдоразметку.
