# R1/A — границы наблюдений и применимость каналов

Дата: 2026-09-24. Ответ на ревью B после R1/A1. Статус: **описательный аудит,
не утверждённые интервалы непрерывности**.

## Что можно воспроизвести

Скрипт `analysis/build_r1_coverage_audit.py` читает те же 79 clean Parquet,
точный состав и размеры которых сверены с M1 `data_quality.json`. Для каждой
пары канал × источник × год он сохраняет первый и последний фактически
наблюдавшиеся моменты, число записей, число дней с записями, число точных
`Неисправен` и `Норма`. Справочник каналов сверяется с хешем M1 manifest.
Исторических дат подключения или отключения в нём нет.

На полном M1: 259 453 121 принятая запись, 12 622 наблюдавшихся каналов,
68 513 строк границ по каналам и источникам. Для 6 115 962 записей канал
отсутствует в текущем справочнике. Точных сообщений `Неисправен` — 414 299;
из них 405 112 имеют известный тип и 9 187 — неизвестный, как в ревью B.
Восемь источников дают
события за 2019, 2020, 2022–2026 годы; между первой и последней календарной
частью отсутствуют все месяцы 2021 года и июль 2026 года. Архив 2026 года
заканчивается 30 июня, а отдельный пример содержит 1 августа.

Файл `channel_observation_bounds.parquet` содержит **границы событий, а не
интервалы доказанной наблюдаемости**. Для каждого ряда
`continuous_observation_status=unverified_events_only`; для канала текущего
справочника `historical_applicability_status=unverified_no_effective_dates`.
Между двумя записями мог быть штатный покой, отсутствие связи либо пропуск
выгрузки — текущие файлы не различают эти случаи. Даже события в каждый день
не доказывают полноту каждого часа. Поэтому подтверждённых интервалов
непрерывности и исторической применимости сейчас **0**; аудит не разрешает
`target=0` и уверенное новое начало только по первым/последним сообщениям.

## Воспроизведение

Из корня проекта с полным локальным M1:

```powershell
.\.venv\Scripts\python.exe -X utf8 analysis/build_r1_coverage_audit.py --input-manifest output/milestone1/full_20260922/manifest.json --output output/r1-coverage-audit-repeat
.\.venv\Scripts\python.exe -m unittest analysis.test_build_r1_coverage_audit -q
```

При переносе M1 можно передать `--channels-dictionary` и
`--objects-dictionary` с локальными путями; их SHA-256 обязаны совпасть с M1.
Текущий локальный результат: `output/r1-coverage-audit-full-20260924-v2/`.
Parquet: 1 073 629 байт, SHA-256
`e6b5b4ed459c86eae1cb174dc148845a6103eb1b28230cd1da28e34dad73399c`.
Отчёт и manifest содержат хеши входов и выходов. `output/` не помещается в Git;
скрипт и этот документ доступны B в общей ветке `ML`.

## Решение для совместной приёмки

При данных только из текущего пакета A не может подтвердить непрерывность
журнала по каждому каналу или даты применимости канала. Правило B о
достаточной предыстории и полном будущем окне остаётся технически
неприменимым к массовой разметке. Для продолжения нужно либо получить
независимое свидетельство покрытия, либо совместно определить более узкую
операционную цель с явно указанными допущениями. Пока B сохраняет `unknown`
для неподтверждённых окон, а A не меняет этот статус на `0`.
